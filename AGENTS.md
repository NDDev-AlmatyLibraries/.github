# Organization profile maintenance

This repository owns its public organization introduction and cover. Edit
`profile/README.md` and its local assets here. Keep the introduction in English
and website links on `nddev.ai`.

Do not publish private system details, customer data or NDA material. Preserve
the existing organization avatar unless the owner explicitly requests a change.

Work on short task branches from `dev` and merge them into `dev` with merge
commits. The `promotion` workflow moves `main` to the checked `dev` commit.
